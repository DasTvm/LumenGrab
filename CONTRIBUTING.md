# Contributing

**Pull requests are currently not accepted.** The project is in early development and the maintainer is
setting the direction alone.

You are welcome to read the code and use it for noncommercial purposes under the
[PolyForm Noncommercial License 1.0.0](LICENSE).

If this changes later, contributions will be accepted under these terms: your contribution is licensed under
the same license as the project, and the maintainer may also use it commercially.

Please never post secrets, personal data or screenshots of private content in issues.
