# Roadmap

Work happens in small milestones. Finish, test and commit one before starting the next.
Source: AGENTS.md section 7.

- [x] **M0 Scaffold**: Tauri 2 + React + TS + Tailwind + shadcn, lint/format, Vitest, Playwright, browser mock mode, CI, tray icon.
- [ ] **M1 Capture MVP**: global hotkey, area / window / fullscreen capture, save to file + clipboard, multi-monitor + mixed DPI.
- [ ] **M2 Quick Access Overlay**: copy, save, edit, drag out, auto-close.
- [ ] **M3 Document model + `.lumengrab` format**: schemas, read/write, migrations scaffold, golden fixture v1, preview, file association.
- [ ] **M4 Editor**: crop/resize, annotations, redactions, undo/redo, export PNG/JPG/WebP.
- [ ] **M5 Presentation**: backgrounds, padding, radius, shadow, aspect presets, window frames.
- [ ] **M6 History, pin, OCR, All-in-one capture mode.**
- [ ] **M7 Screen recording** (MP4/GIF, audio, click/keystroke overlay).
- [ ] **M8 Scrolling capture.**

Later: video editor with smart zooms, device mockups, 3D tilt, local auto-redact, multi-format export, user-configured upload targets.
